市況ニュースには「大引け」「前場」「休場」「短縮取引」といった言葉がよく出てきます。どれも、株式市場が「いつ開いていて、いつ閉まっているか」に関わる言葉です。

結論から言えば、**株式市場は1日じゅう開いているわけではなく、国ごとに決まった時間だけ取引が行われます**。この記事では、東京と米国の取引時間と休みの日を、3つのポイントに分けて整理します。

## ポイント1: 東京市場は9時〜15時30分、お昼休みがある

東京証券取引所の取引時間(立会時間)は、午前と午後の2つに分かれています。

| 呼び方 | 時間 |
|---|---|
| 前場(ぜんば) | 9時〜11時30分 |
| 昼休み | 11時30分〜12時30分 |
| 後場(ごば) | 12時30分〜15時30分 |

合わせると1日5時間半です。後場の終わりは、長いあいだ15時でしたが、2024年11月5日から15時30分に延びました。

ニュースの言葉と結びつけると、次のようになります。

- **寄り付き**: その日の最初の取引。9時に決まる値段が「始値」です。
- **前引け**: 前場の終わり(11時30分)。
- **大引け**: 後場の終わり(15時30分)。ここで決まる値段が「終値」で、ニュースで「日経平均の終値は〜円」と伝えられるのはこの値です。

2024年の変更では、終わりぎわの決め方も変わりました。15時25分から5分間は注文を受け付けるだけで売買を成立させず、15時30分に、集まった注文をまとめて突き合わせて終値を決めます。このしくみを「クロージング・オークション」と呼びます。

## ポイント2: 米国市場は日本の夜中、夏と冬で1時間ずれる

米国の株式市場(ニューヨーク証券取引所やナスダック)の通常の取引時間は、**米東部時間の9時30分から16時まで**です。東京とちがって、昼休みはありません。

これを日本時間に直すと、季節によって1時間ずれます。

| 時期 | 日本時間での取引時間 |
|---|---|
| 夏時間(サマータイム)のあいだ | 22時30分〜翌朝5時 |
| 標準時間(冬)のあいだ | 23時30分〜翌朝6時 |

米国には、春から秋にかけて時計を1時間進める「夏時間」のしくみがあります。日本にはこのしくみがないので、日本から見ると、米国の取引が春から秋は1時間早く始まって早く終わることになります。

日本の朝のニュースで「前夜の米国株」と言うのは、このためです。米国の取引は、日本で多くの人が寝ているあいだに始まり、朝起きるころに終わります。そして、米国の終値が出たあとに東京市場が開くので、米国株の動きは、その日の日本株の出だしを見る材料の1つになります。

## ポイント3: 休みの日は国によってちがう、「半日だけ」の日もある

どちらの市場も、土曜と日曜は休みです。そのほかの休みは、それぞれの国の祝日によって決まります。

**東京市場**は、日本の祝日と年末年始が休みです。その年の最後の取引日を「大納会」、新年の最初の取引日を「大発会」と呼びます。

**米国市場**は、米国の祝日に休みます。ニューヨーク証券取引所の予定表によると、2026年の休場日は次の10日です。

| 日付 | 祝日 |
|---|---|
| 1月1日 | 元日 |
| 1月19日 | キング牧師の日 |
| 2月16日 | ワシントン誕生日(大統領の日) |
| 4月3日 | グッドフライデー(聖金曜日) |
| 5月25日 | メモリアルデー(戦没者追悼の日) |
| 6月19日 | ジューンティーンス(奴隷解放の記念日) |
| 7月3日 | 独立記念日の振り替え |
| 9月7日 | レーバーデー(労働者の日) |
| 11月26日 | 感謝祭 |
| 12月25日 | クリスマス |

日本のゴールデンウイークやお盆の時期も、米国市場はふだんどおり開いています。逆に、日本の平日でも、米国が祝日なら「前夜の米国株」の終値はありません。

もう1つ、米国には**「短縮取引」**の日があります。取引は行われますが、ふだんより3時間早い、米東部時間の13時に終わる日です。2026年は、感謝祭の翌日の11月27日と、クリスマスの前の日の12月24日がこれにあたります。冬の時期なので、日本時間では夜中の3時に取引が終わります。

休みの前後や短縮取引の日は、取引に加わる人が少なくなりやすく、売買の量が減ります。売買が少ないと、少しの注文でも値段が動きやすくなるため、ニュースで「薄商い(うすあきない)のなか」と断り書きがつくことがあります。

## まとめ

- 東京市場は、前場が9時〜11時30分、後場が12時30分〜15時30分。後場の終わりが「大引け」で、その値段が「終値」
- 米国市場は、米東部時間の9時30分〜16時。日本時間では、夏時間のあいだは22時30分〜翌5時、冬は23時30分〜翌6時
- 休みの日は国ごとの祝日で決まるので、日本と米国でそろわない日がある
- 米国には、13時(米東部時間)に終わる「短縮取引」の日がある
- 休みの前後や短縮取引の日は売買が少なくなりやすく、値動きの読み方に少し注意がいる

取引時間と休みの日を知っておくと、「なぜけさは米国株の終値がないのか」「なぜきょうは値動きが小さいのか」といったことが分かり、毎日の市況ニュースが読みやすくなります。なお、休場日や取引時間は変わることがあるので、最新の予定は取引所や証券会社の案内で確かめてください。
